# 北大医疗 · 企业职工医疗健康管理 H5 Demo（员工端）

单文件 H5 演示，无构建、无依赖，直接打开 `index.html` 或访问 GitHub Pages 即可。

## 页面结构

- 智小安（首页）：问候 + 整行居中搜索框 + 5 个热门词 + 10 宫格服务入口（全部直达详情）+ AI 匹配条 + 热门服务（活动轮播置顶，无额度卡）
- 选服务：顶部模糊搜索（按名称/症状过滤）+ 五大模块折叠面板（可同时展开多个），共 27 项
- 服务详情：服务包含、适用人群、覆盖范围、支出来源、服务流程、服务机构、预约
- 预约（独立页面）：按服务类型显示不同字段（院区/就诊方式/咨询主题/培训人数/康养天数等），确认后出预约码
- 我的权益：6 项企业健康服务权益（体检/就医绿通/五高/EAP/急救/减重），含次数、剩余、有效期，可点进服务详情
- 健康讲座：列表页含全部/未开始/进行中/已结束；未开始仅可查看，进行中可报名，已结束可看回放
- 发现：讲座、八大行业配置案例（可进详情页）、健康科普（正文+相关服务）
- 我的：额度余额（点击进入独立的额度使用明细页，含服务/项目/时间/机构/金额与合计）、预约记录（默认 3 条 + 查看全部）、健康档案、设置
- 消息中心：未读数与角标一致，可逐条查看（跳转对应报告/预约/服务），支持全部已读
- 我的预约：全部/待服务/已完成/已取消四个状态筛选
- 预约：服务预约与讲座报名都会写入预约记录，可在"我的"改期或取消
- 交互：深度问答（问题 → 年龄 → 推荐方案）、全站搜索（关键词高亮 / 最近搜索）、签到、消息已读、服务关注
- 动效：Tab 页淡入与详情页推入转场、首页与详情页滚动吸附导航、选择条上滑与计数弹跳、预约成功对勾描边与票据上浮、额度进度条入场动画

## 设计说明

色系沿用暖橙（平安橙的视觉基因），首页以服务为导向：顶部直接摆出服务搜索与 10 个高频服务入口（体检、就医、五高、心理、急救、云门诊、减重、讲座、档案、权益），下面接可一键预约的 service 卡，权益额度与活动位后置。服务卡按模块用筛查橙、慢病绿、就医蓝、特色玫红、应急金区分，每个服务配独立图标。业务内容取自北大医疗企业职工医疗健康管理系列产品配置表与八大行业案例。

## 内容口径

- 全国履约：不受时空地域限制的服务
- 属地履约：限北大医疗地域及资源限制
- 支出来源：职工福利费 / 工会经费 / 企业安全生产费 / 社保 / 商保 / 企康 / 自费

演示数据仅用于产品沟通，不构成真实报价或医疗建议。
